# v0.1.0 代码变更记录

日期：2026-11-03。依据需求与系统设计v0.1.0，保留旧86项API，增加31项操作；117操作、90条规范化路径、44表由接口合同及迁移测试核对。软件实测结果以[验证记录](验证记录-v0.1.0.md)为准。

## 业务变化

- 主LangGraph先固定调度清单，再串行调用五类编译私有子图。共享父执行权、模型、期限、取消和工具预算；最终事务统一提交。角色状态、调用归属与整轮统计分别记录。
- 管理员模板草稿、发布版本、专属资料、下架与逻辑删除。发布冻结版本和文件清单；采用不重新生成，创建独立个人配置、计划、练习。资料异步导入个人库，失败保留成功文件，全部成功才自动关联。
- 计划和独立练习可直接编辑并显式保存。不可变修订支持历史快照、乐观冲突和答案读取；既有答案不调模型，缺少答案创建解析任务。删除对话不删除独立练习。
- 双端新增角色配置、模板与资料管理、模板预览采用、导入进度、学习内容双页签及执行事实。用户端延续手机平板响应式，管理端桌面布局。

## 接口与存储约定

- 新增操作以接口文档第10节为合同；保留旧方法、operationId和规范化路径，PUT也参与合同统计。模板预览仅include_answers=true时返回答案正文，默认不下发。
- 计划内容更新保留当前name；title只作完整结构投影，重命名仍独立。练习历史消息卡片使用原修订，Q-02绑定原题，Q-08/Q-09按expected_version绑定当前修订。
- mysql_0002保留mysql_0001不重写；回填旧计划、题目修订与已绑定消息/任务快照。MySQL权威正文、Chroma派生索引及旧安装文件保留。新安装依次执行两迁移。
- 五角色首次允许当前已启用且未删除的MCP/Skill；之后新增能力需管理员授权，初始化不覆盖已有角色。新安装不预置模型、MCP、模板；内置Exa按需使用，每消息仍只显式选一Skill。
- 模板预览和监控不暴露管理员资料正文、用户私有正文、凭据或子智能体完整输出；占位来源只显示名称定位，导入后映射本人就绪资料。
