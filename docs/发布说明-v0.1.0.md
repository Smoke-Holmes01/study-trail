# 学迹 0.1.0

本版在 0.0.5 的双端平台上新增多智能体协作、管理员学习模板，以及可直接编辑的计划和独立练习集。

## 新增功能

- **多智能体协作**：主 LangGraph 串行调度学习计划、答疑讲解、练习生成、答案解析、作答反馈五类私有子图。主子共享模型、执行期限、取消状态和工具预算；必要角色与主汇总全部成功后才统一保存，失败不覆盖已有计划。
- **学习模板**：管理员维护草稿、发布版本和专属资料，支持下架及逻辑删除。用户预览后采用独立个人副本，不重新调用模型生成；管理员更新不覆盖个人修改。
- **模板资料导入**：支持导入新建或已有个人知识库、后续补导入、逐文件状态和失败重试；保留成功文件，全部成功后自动关联知识库。未导入来源显示占位，不能打开管理员原文。
- **个人学习内容编辑**：学习内容弹窗提供计划和练习双页签。计划支持阶段、任务、耗时及资料编辑；独立练习支持题干、答案、解析和计划关联。已有答案直接读取，缺少答案才请求推导。
- **角色配置与运行统计**：后台维护固定角色职责及允许能力；任务展示真实角色状态，区分用户整轮、角色执行和物理模型/工具调用，不展示内部推理或完整子任务结果。

## 修复与兼容

- 通过不可变修订冻结历史题目、答案及其独立来源；个人编辑或删除不改写历史消息，删除对话保留独立练习。
- 修复复合请求重试时目标题目漂移、计划运行中重命名造成回复标题不一致、跨智能体和跨题目状态残留、模板重导确认跨对象残留及失效角色授权无法清理。
- 保留旧 86 项 API 操作，新增 31 项，合计 **117 项操作、90 条规范化路径**；同步 OpenAPI 和前端类型。
- 用户端新功能延续电脑、平板和手机响应式布局，管理端保持桌面布局。
- 独立验证环境与日常环境使用不同项目、配置、存储和进程登记，拒绝混用运行身份；改进旧结构备份、实际迁移版本记录与恢复核验。

## 安装与升级

- 运行栈继续使用 **MySQL 8.4.13 + Chroma 1.5.9**；关系数据、正文与权限以 MySQL 为准，Chroma 是派生索引。
- 新增 `mysql_0002`，表数由 31 增至 **44**（不含 Alembic）。新安装依次执行 `mysql_0001 → mysql_0002`，既有 MySQL 安装保留数据增量升级；不重写 `mysql_0001`。
- 升级前必须完成协调备份、独立恢复核验、维护排空及停止写入，再使用 `tools/apply_upgrade.py --report <已核验manifest>`，核验成功后显式恢复服务。失败保留维护状态，禁止静默 stamp 或破坏性降级。
- 新安装不预置模型、MCP、模板或模型用途绑定；管理员自行配置外部服务。五固定角色首次允许当时有效的 MCP/Skill，重复初始化不覆盖已有配置，也不自动扩大授权。
- 内置指南通过已有管理员显式刷新，保留历史修订；不自动覆盖日常指南。
- `.local/v004`、Compose 项目 `study-trail-v004` 和备份格式版本 `0.0.4` 是兼容标识，不能据此判断应用仍是旧版。隔离验证项目为 `study-trail-v010-verify`。

## 验证结果与边界

- 后端全量 **143 项通过**；后补引用与运行身份边界的六文件 **41 项复验通过**，与全量有重叠，不相加为独立用例总数。
- 前端 **52 项单测、12 项浏览器业务、42 项 Chromium/WebKit 响应式模拟**通过；类型生成、类型检查与生产构建通过。
- 空库安装、带旧数据的增量迁移、独立备份恢复核验，以及本机日常升级和启动检查通过。
- 上述业务回归使用确定性模型/工具替身及真实本地 MySQL/Chroma；未验证真实外部模型组合、移动设备实机、Linux 运行、性能或教育效果。Linux 仅脚本静态检查。
- 不增加知识正确性自动复核、综合掌握度、计划打卡或自动重规划；测试通过不构成全领域答案正确性保证。
