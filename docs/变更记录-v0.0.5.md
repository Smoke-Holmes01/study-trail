# 学迹 v0.0.5 变更与验证记录

日期：2026-11-01。发布内容为前端响应式适配、旧版本冗余代码清理及 MySQL 存储实现；业务基线和九大模块保持不变。

## 主要变化

- 用户端适配手机、平板和电脑：底部导航、资源抽屉、单栏登录注册、动态可视高度和安全区、触屏输入、模型浮层、文件卡片及学习计划布局。管理端继续使用桌面布局。
- 关系存储完全采用 MySQL 8.4.13：原生类型与约束、行锁、独立 mysql_0001 迁移，31张表；Chroma 1.5.9继续承担派生向量索引，候选必须回查MySQL。当前源码、依赖与Compose不提供PostgreSQL运行路径。
- 删除旧模型/MCP文件解析及回退、过期验收脚本、旧安装统计回填和其他冗余代码；隔离测试使用当前平台结构的合成配置。
- 历史代码、迁移和一次性脚本从src迁出并核验哈希；本机私有脚本限制访问，不随Git仓库发布。历史源码可通过原标签0.0.1—0.0.3追溯，旧数据、密钥、配置和备份保留。
- 应用、API、前端清单和锁文件统一为0.0.5；修复HTML页面标题乱码。保持86项接口操作、67条路径。

## 安装与兼容

当前支持 MySQL + Chroma，不导入或自动删除旧PostgreSQL安装。现有MySQL安装无需因版本号变化执行新迁移。运行目录`.local/v004`、Compose项目`study-trail-v004`、迁移`mysql_0001`和备份格式版本0.0.4是存储合同标识，继续沿用；备份恢复保持既有格式兼容，不改写历史备份。

生产初始化不预置模型或MCP扩展。已有数据库中的管理员配置、凭据、用户和学习资料保持原样。新版源码指南不会自动覆盖数据库指南；如需采用，按README使用已有管理员显式刷新后再初始化。
