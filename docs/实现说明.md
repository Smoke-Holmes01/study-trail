## 架构与合同

采用模块化 Python 后端，FastAPI 与独立 worker 共享 PostgreSQL/pgvector 和私有文件目录。前端为 Vue3/TypeScript/Vite，使用 Vue Router 与 Pinia。没有教师或管理员页面；学生可在五标签表单开关预置MCP/技能，不编辑服务定义、凭据或技能正文。

数据库仍为设计中的19张表。除设计字段外，幂等记录增加内部 method/path/resource_refs，以正确检查一次批上传的多个资源是否已删除；不增加公开 DTO 字段。数据库约束、外键与触发器保护归属、状态、唯一性和历史 SET NULL 关系。迁移采用冻结 SQL，后续模型变化不影响已有迁移内容。

59个业务接口保持 `/api/v1`、UUID、snake_case、统一 JSON 信封、HTTP 状态与错误码。实际 OpenAPI 导出后生成前端类型。任务 SSE 使用完整快照与 revision，不把 token 增量拼接作为恢复机制。

本机实际数据库为 PostgreSQL17.11、pgvector0.8.7，镜像已按摘要锁定。模型目录严格校验，未知字段导致CONFIG_INVALID，非法配置不影响非AI资源管理；配置快照不保存密钥。

## 任务与提交

领取使用 PostgreSQL 短事务和 SKIP LOCKED；全局容量锁保障多个 worker 入口仍遵守 AI2、文件1。5秒心跳、30秒租约，每次领取有唯一 claim_token，截止时间从成功领取开始固定。

停止与最终提交锁任务行；修改计划随后锁计划。正式消息、计划、习题、来源关系及 succeeded 一起提交。停止先接受、失去租约、期限到达、目标删除、内容版本冲突或来源失效均阻止正式保存。完成先提交则后续停止返回真实成功。

后台保存批量预览。浏览器显式处理 offline/online，重连原任务；旧连接回调不能污染新连接。网络响应不明时保留原幂等键，人工重发仍查询原受理结果。修改草稿前先确认原未知请求，以避免误造第二份请求。

服务重启会处理失效租约，不自动续跑 LangGraph。物理文件清理由内部任务幂等完成，失败按60秒起、1小时封顶退避，仍不可通过学生任务接口访问。

## 文件、上下文与 AI

PDF 逐页文字、DOCX 段落/表格、TXT BOM/严格 UTF-8/GB18030；扫描与加密不可读文件明确失败。目标分块1200字符、重叠200；完整嵌入成功后原子发布 ready。预览使用持久文本，去掉分页中检索重叠的重复显示，并支持来源块定位。

聊天图片与知识库完全隔离。静态图片实际解码后保存，消息受理时由 staged 转 bound；新消息不能复用已绑定附件，重试复用原消息。仅图片请求可通过视觉识别得到检索主题，图片字节不进入知识库索引。

上下文保留最近六个完整成功轮次、未配对学生原输入和全部历史图片；摘要只覆盖明确记录的旧完整轮次。全量请求仍超预算就失败并保留输入，不能丢图或静默更换模型。

RAG 仅检索所属 ready 文件：BGE-M3 dense1024、精确 cosine20、重排6；重排失败沿用向量顺序。覆盖后进入受限MCP选择：最多三轮六次调用位置，模型按需调用；每次Exa解析最多5条并按URL合并，不承诺总数5条，使用MCP文本归一化；失败保留有效知识库依据。停止和总截止不能当作普通降级吞掉。

计划使用完整 PlanPayload 及应用语义校验，最多修复一次；名称独立于内容版本，内容修改保留当前名称。期限与显式总时间约束有学生原文校验。题目生成使用结构化结果，首轮不输出隐藏答案；资料原题/答案必须匹配实际片段，明确题目反馈不形成综合掌握度。

## 前端与内容安全

按学迹原型使用米白/暖灰/陶土色、完整双主题、64px导航、280px资源栏及两个主页面。五标签智能体、设置、计划、删除、文本和图片预览均为辅助弹窗。头像仅展示；行加号创建所属对话；模型选择位于输入工具栏。

草稿在当前浏览器内存中按账户/对话隔离，重新认证可恢复非密码草稿；退出清理该账户草稿，刷新不承诺恢复未发送内容。异步操作捕获原对话，切换后不会写入另一对话的输入或订阅。计划标签只在对应修改正式成功时清除。

Markdown 禁原生 HTML与自动外部图片；公式不可信配置并局部回退；代码不执行。候选内容中的链接及来源入口在正式成功前不可打开。Enter/Shift+Enter/输入法组字与原生 dialog 焦点/关闭行为均有实现。


## 0.2.1 新能力及合同

config/model.json支持多个兼容供应商与公开模型ID映射；config/mcp_config.json由部署者定义服务、传输和白名单；config/skill提供SKILL.md目录。凭据使用环境变量引用，调用时解析。选择保存在智能体，0004新增mcp_server_ids、skill_ids与消息skill标签；旧智能体迁移回填，新智能体按目录默认。

每条消息仅显式选择一个开启技能；受理冻结正文、散列版本、MCP选择与模型配置；重试保留ID但取当前正文并复核开启状态。项目指南默认关闭，开启后通过/选择，不增加主页面。默认三项学习技能开启。

MCP工具阶段不会因coverage足够而硬跳过；可零调用，最多三轮六次且可缓存重复参数。关闭、普通失败、容量和取消分别处理。引用协议source:UUID转数字角标与浮层；全文从头、计划定位。来源校验只检查ID集合，正式提交关联整个上下文来源集合，不能声称语义自动验证或仅保存正文实际引用。

当前全部实现和配置以源码为准。软件运行验收见独立记录；本次静态同步未执行模型、MCP、数据库迁移或测试。
