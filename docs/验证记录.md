## 本轮修复的缺陷

- SQL表达式不能用布尔值回退判断；修复预览/消息分页。
- 父资源级联删除存在 SET NULL 中间状态；改为只校验新引用或归属变更。
- 首次恢复未登录会话不应抢占注册路由；修复启动导航。
- MCP2.x提供 `is_error`；适配后匿名 Exa 正常返回来源。
- 浏览器离线不一定关闭既有 SSE；显式监听 offline/online，忽略旧连接回调。
- 已绑定图片编辑后必须重新暂存；修复本地附件状态和丢失响应下的草稿删除。
- 非密码草稿按账户存于浏览器内存；重新认证和切换对话不混写。
- 网络未知响应保留幂等键；已知受理后立即接上任务，避免重复请求。
- 检索块有重叠而预览全文不应重复；修复预览投影和来源位置。
- 分块传输超限最初被框架改为400；修复为统一413错误。
- 配置读取加行锁，避免受理快照混合旧提示词与新关联库。
- 首次旧资源列表响应可能晚于创建结果；按加载版本忽略旧响应，切换智能体/对话同样阻止过时加载。
- Windows Python虚拟环境含启动器子进程，PowerShell也会自动解析JSON日期；停止时按已验证的父进程树处理，启动检查统一日期格式。
