日期：2026-10-21。业务基线：需求分析与系统设计0.0.2。实际85项操作、67个路径、29张业务表，当前迁移0006。

## 实施结果

- MCP参数约束类型非法时返回422及字段错误，失败不保存修订，表单保留草稿。单工具结果超限丢弃并降级，整体上下文超限、取消和总超时终止。
- 三项内置技能默认选择由服务端稳定标识规则决定，冲突写入拒绝；旧修订标记不改变规则，已有智能体选择保留。
- 计划任务来源UUID拒绝重复，知识点至少一项；设计Schema、实际验证器和生成类型同步，保留一次格式修复、期限、来源及版本检查。
- 管理端增加中文安全错误说明及原码，未知错误不回显。指南改为数据库配置管理、文件仅初始化导入、限制以页面为准。
- 数据库字典准确描述实际29表、幂等owner/key和操作者审计；RT-01、逐指标报表覆盖、401/403及部署参数合同一致。
- 0006只从文件可靠指纹回填缺失块指纹，无法确认或冲突中止，随后设置非空；0001—0005内容未改写。
- 显式 --refresh-guide 创建新版指南修订，保留旧修订及启停状态；重复执行不重复创建修订。普通初始化继续保护后台修改；演练复用原密钥环。

## 本机备份、重置及恢复

用户明确授权重置。先验证原库完整恢复和凭据解密，再重建 study_trail 业务库与私有学习存储，初始化0.0.2和study_admin。旧普通账户、学习数据和平台历史不在新日常库中，仍保存在备份。新库初始只有管理员；本机页面核验另产生管理会话和审计记录。

备份目录：src/.local/backups/unify-0.0.2-20261021/，包含本机秘密，被Git忽略，不可发布。

| 产物 | 作用 |
| --- | --- |
| source-before.zip | 实施前源码、需求和设计归档，完整性已核验 |
| database.dump | 原0005日常库的PostgreSQL自定义格式备份 |
| storage/、retired-storage/ | 校验后的私有文件副本及重置时移入的原文件 |
| backend.env、infra.env | 原部署连接和密钥；原环境文件未改写 |
| admin-bootstrap.json、admin-bootstrap-before-reset.json | 原管理员登录信息；不是新密码 |
| rehearsal.json | 全部表恢复、业务哈希、存储、升级及凭据解密结果 |
| protected.json | 原迁移、开题报告和环境文件SHA-256 |

原库实际恢复到 study_trail_rehearsal_v002_backup，全部表摘要与原库一致，随后完成0005→0006演练；study_trail_rehearsal_v002_fresh用于全新安装。两个副本及备份均保留，部署密钥未替换。

新管理员登录信息在 src/.local/admin-bootstrap.json，仅本机保存。过程记录及截图位于 src/.local/v002/。验收结束停止本轮应用和数据库容器，保留数据卷与备份。后续启动Docker Desktop后，从毕业设计目录运行 `.\src\scripts\start.ps1`，停止使用 `.\src\scripts\stop.ps1 -Database`。

恢复时先停止应用，在独立新库恢复database.dump，使用匹配的原存储、密钥和0.0.1源码验证后再切换；或在副本升级0006并显式刷新指南。不能直接覆盖唯一备份。0006约束回退不能恢复已重置的学习数据；0005不支持破坏性降级。
