# 学迹 0.0.3

发布日期：2026-10-21。相对0.0.2，集中修复首次部署、管理配置删除、检索引用及链接展示问题。

## 修复摘要

1. **初始化不再带入个人模型配置**：新安装只初始化管理员、必要提示词、内置技能和运行限制，模型及其他MCP扩展由管理员配置；空配置仍能正常启动与登录，缺少必要模型时在受理前说明原因。隔离测试通过专用工具显式创建模拟配置。
2. **管理员可删除四类配置**：模型、MCP、提示词及Skill增加逻辑删除与确认入口。仍被生效用途或智能体使用时拒绝；历史修订、加密凭据和任务快照保留。新增0007迁移，不复活已删除的内置指南，不复用被删除的稳定标识。
3. **知识库按需检索**：问候、闲聊和能力状态询问跳过检索，普通问答无资料时也能使用模型知识，明确教材或联网请求分别走所需分支。
4. **只展示实际引用**：候选资料不自动挂在回复下方；只保存正文、习题和计划实际引用的来源，继续验证归属及来源存活，防止无关PDF反复出现在参考列表。
5. **Exa内置搜索及执行状态**：系统内置web_search_exa和web_fetch_exa，无需管理员添加或绑定；旧Exa配置和凭据保留，避免重复执行。消息展示程序记录的检索、工具发现、成功或失败状态，不把模型自述当作连接验证。网页来源归一化后可作为真实引用，失败保持降级边界。
6. **可点击、可读的链接**：裸网址和纯网址行内代码可点击、换行并安全地在新标签打开；命令与代码块保持原样。回答提示词要求以有意义的产品、平台或文档名称生成`[名称](URL)`，不直接以长网址作为名称，不编造下载地址。

需求、设计与源码追踪已同步。本版仍为九模块、双端布局，不增加内容自动校验、独立模型复核、综合掌握度、计划打卡或教师审核。

## 升级

先备份并核验恢复，再执行`alembic upgrade head`至0007。已有指南需要刷新时，显式运行`tools/bootstrap_platform.py --admin-login your_admin --refresh-guide`；该操作保留历史修订与启停状态，其他管理员配置保留。逻辑删除保留审计及任务所需历史数据，存在删除墓碑时拒绝0007降级。

本地重置属于此前用户单独授权的测试准备，不是本版启动或升级行为。仓库不包含本机账户密码、模型密钥、数据库、上传资料或备份。

## 验证

后端103项、前端32项、双端浏览器11项；OpenAPI类型生成、类型检查、生产构建及关键静态检查通过。接口86项、路径67条、业务表29张，迁移0001—0007。

检索和工具行为回归采用模拟提供商；实际Exa仅验证工具目录发现，没有在本轮执行真实搜索、抓取或付费模型调用。命名链接是生成指令，未进行真实模型依从性实验。性能、教学内容质量、全部提供商兼容和Linux完整启动保持独立验证边界。
