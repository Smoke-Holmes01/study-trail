# 用户端响应式适配验证记录

日期：2026-11-01。基线：v0.0.4。范围仅为用户端；管理端、后端接口、数据库和部署方式不变。原有历史验证记录不作追溯修改。

## 实现

- 手机底部导航（智能体、知识库、我的）及资源抽屉；平板竖屏紧凑导航与抽屉，横屏/电脑并排布局。
- 断点：小于768px为手机；768–1023px为紧凑平板；1024px起并排。小于1024px且高度不超过500px采用手机横屏布局。
- 桌面折叠偏好与临时抽屉状态独立，抽屉使用原生dialog约束焦点；业务弹窗打开时关闭抽屉。
- 用户端移除1024×768最低画布限制；管理员页面继续显示原小窗口提示。
- 使用动态可视高度、VisualViewport、安全区处理输入区和浮层；触屏或窄屏Enter换行，按钮或Ctrl/Cmd+Enter发送，中文输入法组合事件不提交。
- 手机文件卡片、计划列表/详情、智能体编辑标签页、单栏登录注册；保留既有文件格式限制及操作逻辑。

## 自动验证

- `npm run build`：类型检查及生产构建通过。
- `npm test`：7个文件、32项通过。
- `scripts/test-e2e.ps1`：原有11项浏览器回归通过；隔离MySQL测试库及合成模型，不代表真实模型服务或全部业务场景验收。
- `npx playwright test --config playwright.responsive.config.ts`：Chromium/WebKit共42项通过。接口使用测试合成数据；包含两种主题、抽屉关闭、模型菜单、智能体编辑、手机Enter换行、计划列表/详情、文件卡片、设置弹窗、旋转后草稿保留及页面无横向溢出检查。
- 响应式尺寸：440×763、440×956、838×390、956×440、820×1180、1180×820、600×900、1024×768、1440×900；另含440/820/1180宽度登录注册布局。
- 截图：`src/.local/v004/responsive-results/`，包含工作区、设置、知识库和注册页。人工抽查手机工作区、手机文件卡片、注册页及平板深色设置截图。

运行前设置项目浏览器缓存：PowerShell在frontend目录执行 `$env:PLAYWRIGHT_BROWSERS_PATH="$PWD/../.local/v004/playwright"`；首次执行 `npx playwright install chromium webkit`。响应式测试配置自行启动5175端口的本机Vite服务，不需要连接日常数据库。

## 验证边界

上述结果为Windows上的浏览器自动化与尺寸模拟，不是iPhone/iPad实机验收。尚需目标设备Safari访问部署网址，检查真实软键盘、系统中文输入法、安全区、地址栏伸缩、系统文件选择和缩放。附件/技能跨屏保留及流式生成期间旋转未进行单独实机测试。未新增网络暴露方式，未执行部署，不承诺内容正确性或学习效果。
