# 平台配置初始化来源

v0.0.2运行配置以数据库为唯一来源，通过管理端维护。全新初始化不添加任何模型或MCP服务，也不创建默认生成、嵌入、重排绑定。

`backend/tools/bootstrap_platform.py`只初始化八个流程提示词、四项内置技能、运行限制及显式指定的管理员。管理员登录后自行添加外部模型和MCP服务，填写连接与凭据，再指定各用途的生效模型。没有默认生成模型时可启动平台、登录及管理账户；学生端提示尚未配置，创建智能体与AI请求返回明确配置错误。仅配置生成模型即可普通答疑；文件索引需要嵌入模型，检索排序需要重排模型。

model.json、mcp_config.json仅为旧格式兼容和隔离测试样例，普通初始化与运行均不读取它们补建模型或服务。`tools/seed_test_platform.py`显式加载模拟测试配置，并拒绝测试库以外的数据库。skill/*/SKILL.md及initial_prompts.json提供基础内容；重复初始化不覆盖管理员编辑、模型、凭据和既有选择，升级不自动删除已有的四个模型。

管理员输入的真实凭据加密保存为不可变版本；不要把真实密钥写进JSON、SKILL.md或普通连接字段。数据库只保存密文；主密钥环由部署环境提供。

后台模型分生成、嵌入、重排三类。生成模型另有开放和图片能力设置；首版仅支持1024维嵌入，已有索引或在途文件处理时禁止不兼容切换。

MCP支持Streamable HTTP与stdio，维护工具白名单、参数Schema和单次超时；stdio程序及目录须位于部署允许列表。秘密以 `header.Authorization`、`header.x-api-key` 或 `env.API_KEY` 等槽保存，界面留空保留已有值。

Skills仅加载每条消息显式选择的一项正文，不执行脚本或附属资源。explain、study-plan、practice在平台启用时默认开启；study-trail-guide需先在智能体技能标签开启，再通过斜杠菜单选择。

后台新建、编辑、启停产生可追踪版本；已受理任务保留当时的配置与凭据引用。用户只选择开放能力，不编辑平台定义。平台配置不提供永久删除。

技能的default_enabled由三项内置稳定标识规则派生，不是管理员可任意修改的默认开关。升级指南使用显式 `--refresh-guide` 操作保留旧修订，普通初始化仍拒绝来源变化时自动覆盖。

当前检索合同补充：知识库按需检索，问候、闲聊及能力状态询问跳过。Exa搜索与网页读取为系统内置能力（web_search_exa、web_fetch_exa），无需管理员添加；原管理员Exa配置及历史凭据保留，系统内置配置存在时不重复调用同一Exa端点。MCP管理继续用于其他扩展服务。只有正文source引用、习题source_ids及计划resource_source_ids实际使用的来源才建立正式关联；候选不自动展示。消息和任务增加execution_info，显示程序执行事实，能力询问不以模型自述当成功验证。配置不等于连通或调用成功，失败保留降级说明；不进行内容正确性自动复核。
